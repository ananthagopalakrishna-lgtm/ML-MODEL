# 📚 Study Hours vs Exam Score Predictor

A Machine Learning project that predicts a student's exam score based on their **study hours** and **sleep hours** using **Linear Regression**. The application provides an interactive web interface built with **Streamlit**, allowing users to enter their study and sleep hours and instantly receive a predicted exam score.

---

## 🚀 Features

- Predicts exam scores using Linear Regression.
- Interactive Streamlit web application.
- Adjustable sliders for study hours and sleep hours.
- Preset input options for quick testing.
- Console mode support if Streamlit is unavailable.
- Clean and easy-to-understand Python code.

---
